# PastForward

History rhymes. Swipe through 550 years, follow each event to its echo today, and see where the pattern may return. Live at **https://pastforward.app**.

## How it is built

- `index.html`: the whole site in one static file. **Generated; do not edit by hand.**
- `src/template.html`: page markup, styles and code. Edit this.
- `data/`: the content.
  - `pairs-*.json`: the 48 rhymes.
  - `echoes-*.json`: extra real occurrences of each pattern.
  - `world-*.json`: what was happening in 8 regions in each year.
  - `headlines-*.json`: a short headline per region per year.
  - `map.json`: the dot-matrix world map, generated by `tools/grid.mjs`.
- `functions/api/`: Cloudflare Pages Functions backed by the D1 database bound as `DB`.
  - `GET /api/scores`: vote totals per rhyme, cached for 60 s.
  - `POST /api/vote`: `{ rhyme, device, vote: 1 | -1 }`.
  - `POST /api/puzzle`: `{ day, device, score }`.
  - `GET /api/puzzle?day=N`: players and perfect scores that day.
- `d1-schema.sql`: database tables. Run once in the D1 console.
- `docs/`: project overview, infrastructure briefs and content specs.

## Build

```bash
python3 tools/build.py      # validates the data and writes index.html
```

The build fails, and lists the problems, if the content breaks a rule: a missing field, an unknown region, a missing world snapshot, and so on.

To regenerate the map, which you rarely need to do:

```bash
cd tools && npm install world-atlas@2.0.2 d3-geo@3.1.0 topojson-client@3.1.0 && node grid.mjs
```

## Deploy

Pushing to `main` deploys to Cloudflare Pages automatically. The project has no build command, and the output directory is `/`.
